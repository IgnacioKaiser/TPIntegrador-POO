# Consignas y anexos oficiales

Esta carpeta permite que un integrante o Codex encuentre las fuentes sin depender de adjuntos de un chat. Los archivos no cambian el programa ni se compilan.

| Ruta | Archivo de origen | Uso |
|---|---|---|
| TPI_2026.pdf | poo_2026_TP_integrador.pdf | Fuente principal de requisitos, restricciones y entrega |
| Lineamientos_TP.pdf | poo_2025_TP_lineamientos.pdf | Lineamientos generales provistos en los materiales; respetar ciclo/fecha del documento |
| anexos/Geometria_Robot_RRR.pdf | poo_geometria_RobotRRR3FD.pdf | Referencia geometrica del robot |

El ZIP de materiales entrega copias de los documentos adjuntos, con nombres simples. No son documentos reescritos por IA.

El firmware esta en ../../firmware/arduino/robotArm_v0.62sim (desde esta carpeta); no reemplazarlo con otra copia sin comparar la version y las modificaciones del equipo.
El archivo original unit_tests_doctest_cpp.zip, si hace falta, se conserva como referencia en ../referencias/pruebas/. Es un ejemplo, no obliga a reemplazar las pruebas existentes.

Si la catedra actualiza una consigna, conservar claro cual es la vigente y registrar fecha/procedencia. No mezclar versiones silenciosamente.
Los informes de otros grupos o anios no son fuente normativa. Solo copiarlos como referencia secundaria si se necesitan para una consulta concreta.
