# Referencias de apoyo

Leer solo lo necesario para la tarea. Estos archivos no sustituyen la consigna oficial.

| Carpeta | Contenido del paquete | Para que sirve |
|---|---|---|
| tps/ | TP2_Req1.pdf, TP2_Req2.pdf, TP2_Req3.pdf, TP2_Req4.pdf | Entender requisitos anteriores y las piezas que se reutilizan |

El codigo propio vigente se consulta en server/ y client/, no en copias de TPs viejos. El firmware vigente se consulta en firmware/. No extraer el ejemplo de pruebas encima del codigo del proyecto.

Jira.csv puede guardarse aqui si el equipo quiere versionar esa exportacion. Sus descripciones/criterios ayudan a organizar requisitos, pero sus estados y responsables no se consideran actualizados: manda la confirmacion del equipo y la evidencia en el repositorio. El archivo puede contener nombres/correos de participantes; revisar su contenido antes de publicarlo.

No copiar bases de usuarios reales, archivos con claves ni ejecutables de otras computadoras. Documentar las dependencias y generar los binarios en cada entorno.
